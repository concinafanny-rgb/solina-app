Créer ma clé sur GitHub
Ce qu’il faut faire sur la page GitHub
  1. Le nom et la durée sont déjà remplis.
  2. Dans Repository access, choisis Only select repositories, puis maison-solina.
  3. Dans Permissions, vérifie que Contents est sur Read and write.
  4. Clique sur Generate token en bas, copie la clé et colle la ici.
